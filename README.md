## 🔧 Setup Notes

- All visual assets are stored in `/images/`
- Certificates are organized in `/images/certificates/`
- Resumes and Gamma PDFs are stored in `/resume/`
- `index.html` is the main homepage
- `style.css` controls layout and branding
- SEO files (`robots.txt`, `sitemap.xml`) are optional but recommended
- Designed for deployment on GitHub Pages, Pyxl, or any static hosting platform
