## 🌐 Deployment

### 🚀 Netlify Setup
1. Push all files to your GitHub repository.
2. Log in to [Netlify](https://app.netlify.com/).
3. Click **New Site → Import from Git**.
4. Select your repo and set:
   - **Build command:** _(leave blank)_
   - **Publish directory:** `.`
5. Deploy your site and verify:
   - [`https://vbsecure360.netlify.app`](https://vbsecure360.netlify.app)
6. Confirm your sitemap & robots accessibility:
   - `/sitemap.xml`
   - `/robots.txt`
